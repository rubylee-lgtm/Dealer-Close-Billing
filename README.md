# 出退貨請款與發票系統（Prototype）

**版號：0.4.0**（見 `index.html` 內 `APP_VERSION`、`meta app-version` 與導覽列徽章）

單一 HTML 檔的純前端原型，模擬經銷／通路出貨、退貨明細匯入、篩選勾選、SKU 小計、扣款與加減項、以及發票開立與結案檢視流程。**無後端、無資料庫**；對帳草稿／列表仍僅在記憶體，**重新整理頁面會清空**。另：**出貨／退貨「部分結算」之累計已結算數量**僅在本次頁面載入期間生效；重新整理時會清除 `localStorage`（鍵名 `dealer-partial-settlement-v1`），因此重新整理後所有單據狀態會回到「未結算」。

## 執行方式

- 以瀏覽器直接開啟 `index.html`，或
- 在本機目錄啟動靜態伺服器後開啟（可避免部分環境對 `file://` 的限制）。

需可連線至 CDN 以載入 React、Tailwind、Babel、PapaParse、SheetJS、Lucide 等資源。

## 技術組成

| 項目 | 說明 |
|------|------|
| UI | React 18（UMD）、Tailwind CSS（CDN）、Lucide 圖示 |
| 語法 | 瀏覽器內以 Babel Standalone 編譯 JSX |
| 檔案解析 | CSV（PapaParse）、Excel `.xlsx` / `.xls`（SheetJS，讀取第一個工作表） |

## 主要功能

### 頂部三個主畫面

1. **正在結算** — 三步驟精靈（見下）。
2. **結算完畢列表** — 草稿與已開立發票的對帳單列表；可從列表開啟「檢視／編輯」彈出視窗（`window.open` + `postMessage` 與主視窗同步儲存草稿、開立發票）。
3. **結案視角（完成樣貌）** — 已結案、鎖定後的摘要與 Net 小計表，可匯出結案明細 CSV。

### 結算三步驟

**Step 1 — 上傳進銷存明細**

- 支援 **CSV**、**Excel**；欄位可對應中英文／常見別名（例如單據類型、單號、通路商簡稱／全名、出／入庫日期、SKU、品名、單價、數量、小計等）。
- 數字會經過正規化（千分位、貨幣符號、`--` 開頭負數等）。
- 日期支援 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD` 與粗略的 Excel 序號。
- 單據類型含「出」「退」會正規成 **出貨**／**退貨**。
- 依出貨日預設篩選區間；可關鍵字搜尋、日期起迄篩選預覽表。
- 同鍵之出貨/退貨列（通路簡稱＋單號＋SKU＋出貨日＋單據類型）會合併為一筆並加總**原始數量**。

**Step 2 — 篩選與選擇單據**

- 通路商下拉、單據類型多選、關鍵字、日期範圍（出貨日或入庫日任一落在區間即納入）。
- 先選通路與單據類型後，可再依條件產生**單號**多選。
- **出貨／退貨部分結算**：表格顯示**狀態**（未結算／部分結算／已全部結算）、原始數量、剩餘可結；預設僅顯示「剩餘可結 > 0」之出貨/退貨（可勾選取消以檢視已全部結算列）。剩餘可結 = 0 的列不可勾選。
- 勾選列後可進入下一步。

**Step 3 — SKU 小計與模擬開立發票**

- 依勾選明細產生可編輯的結算列：**出貨/退貨**可調整「本次結算數量」（不超過剩餘可結）與單價；確認小計前會檢核數量。儲存草稿／彈出視窗儲存或開立時，會依本次結算數量更新 `localStorage` 累計。
- 對帳單編號（如 `DAS-YYMMDD-xxx`）、經銷商、通知信箱、扣款、**加減項**（可正可負）、發票日期等欄位。
- 試算：**發票總額 = 淨額（扣款後）+ 加減項合計**。
- 可匯出含對帳資訊、加減項、SKU 小計、原始明細的 **對帳明細 CSV**。
- 「儲存草稿」會進入結算完畢列表；主流程內亦可搭配後續列表中的彈出視窗做細部編輯與開立發票。

### 列表與彈出視窗

- 草稿可填發票號碼後於列表操作開立（原型內為模擬流程）。
- 彈出頁可編輯明細、加減項、備註等，並透過 `postMessage` 回寫主視窗（`DAS_SAVE_DRAFT`、`DAS_ISSUE_INVOICE_WITH_DATA` 等）。

### 結案視角

- 顯示發票資訊、財務結算卡（出貨／退貨／扣款／調整項）、Net 小計表（可展開／收合）。
- **匯出明細** 下載該案原始明細 CSV。

## 限制與備註

- 對帳單草稿與列表資料僅在記憶體；**部分結算累計**僅存於本機 `localStorage`（非伺服器），清除網站資料或換瀏覽器即不同步。
- 發票號碼等為原型展示用邏輯，非真實稅務或 ERP 串接。
- 若使用「檢視／編輯」彈出視窗，請允許瀏覽器**彈出視窗**，否則會無法開啟。
